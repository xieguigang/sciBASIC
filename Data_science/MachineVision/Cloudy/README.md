# Microsoft.VisualBasic.MachineVision.Cloudy

A managed 3D point-cloud processing library for sciBASIC#, covering the full pipeline from preprocessing to registration, reconstruction, segmentation and industrial inspection applications.

## Features

- SoA point buffers, spatial neighborhoods, voxel/ statistical / radius outlier filters and motion undistortion
- ISS keypoints, FPFH descriptors and feature matching
- RANSAC, ICP, NDT, PCS4 coarse/fine registration and pose-graph optimization
- Poisson surface reconstruction, TSDF fusion and primitive least-squares fitting
- Euclidean clustering, model fitting and semantic classification
- 6-DoF pose estimation, hand-eye calibration, grasp planning, CAD deviation analysis and geometric tolerances

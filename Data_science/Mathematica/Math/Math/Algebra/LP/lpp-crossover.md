# 内点法 + Crossover 求解线性规划：原理、步骤与与单纯形法的比较
这是现代 LP 求解器（Gurobi、CPLEX、Mosek、HiGHS 等）中 **barrier 求解器的标准流水线**：先用原始-对偶内点法（Interior-Point Method, IPM）逼近最优解，再用 crossover 把它“净化”成一个基可行解。下面分四部分详细讲解。
---
## 一、问题设定与预备知识
考虑标准形式的线性规划及其对偶：
$$
\begin{aligned}
\text{(P)}\quad & \min c^\top x \quad \text{s.t. } Ax=b,\ x\ge 0\\
\text{(D)}\quad & \max b^\top y \quad \text{s.t. } A^\top y+s=c,\ s\ge 0
\end{aligned}
$$
其中 $s$ 是对偶松弛变量。最优解（KKT 条件）须满足：
1. **原始可行**：$Ax=b,\ x\ge 0$
2. **对偶可行**：$A^\top y+s=c,\ s\ge 0$
3. **互补松弛**：$x_i s_i = 0,\ \forall i$
由强对偶性，对偶间隙 $c^\top x - b^\top y = x^\top s \ge 0$，最优时为 0。
**单纯形法一句话概括**：在可行多面体的**顶点之间沿棱移动**，每次从一个顶点跳到相邻顶点使目标下降，始终停留在边界上。
---
## 二、内点法的计算原理
### 2.1 核心思想：松弛互补条件
内点法的关键一步是把硬性互补条件 $x_i s_i=0$ **松弛**为 $x_i s_i = \mu\ (\mu>0)$：
$$
F_\mu(x,y,s)=
\begin{pmatrix}
Ax-b\\
A^\top y+s-c\\
XSe-\mu e
\end{pmatrix}=0,
\qquad X=\mathrm{diag}(x),\ S=\mathrm{diag}(s)
$$
几何意义：对每个 $\mu>0$，若可行域有内点，上述系统有**唯一解** $(x(\mu),y(\mu),s(\mu))$，其轨迹称为**中心路径**。$\mu\to 0$ 时，中心路径收敛到最优解集——具体收敛到**最优面的解析中心**，而**不是某个顶点**（这一点正是后面需要 crossover 的根源）。
它也可以从障碍函数角度理解：$x(\mu)$ 是
$$
\min\ \ c^\top x - \mu\sum_i \ln x_i \quad \text{s.t. } Ax=b
$$
的解，对偶性给出 $s_i = \mu/x_i$，即 $x_is_i=\mu$。$\mu$ 越小越接近真解，但对数障碍越陡，越难数值求解。
### 2.2 牛顿方向与每步的线性代数
对 $F_\mu=0$ 用牛顿法。以保持原始/对偶可行的简化情形为例，牛顿方程为三块线性系统：
$$
\begin{bmatrix}
A & 0 & 0\\
0 & A^\top & I\\
S & 0 & X
\end{bmatrix}
\begin{pmatrix}\Delta x\\\Delta y\\\Delta s\end{pmatrix}
=
\begin{pmatrix}
0\\ 0\\
\sigma\mu e - XSe
\end{pmatrix}
$$
其中 $\sigma\in[0,1]$ 是**中心化参数**（$\sigma$ 大→偏向中心路径，稳健；$\sigma$ 小→偏向降低目标，激进）。
**消元得到正规方程**：由第三块解出 $\Delta s=\sigma\mu X^{-1}e - s - X^{-1}S\,\Delta x$，代入第二块再结合第一块，可消去 $\Delta x,\Delta s$，得 $m\times m$ 对称正定方程组：
$$
\boxed{\,A D^2 A^\top \,\Delta y = b - \sigma\mu\, A S^{-1} e\,},
\qquad D^2=\mathrm{diag}(x_i/s_i)
$$
然后回代：
$$
\Delta x = D^2 A^\top \Delta y - x + \sigma\mu S^{-1}e,\qquad
\Delta s = -A^\top \Delta y
$$
这就是每次迭代的全部核心计算：
- **$AD^2A^\top$ 用稀疏 Cholesky 分解求解**，填充由稀疏排序（AMD / nested dissection）控制——这是每步的主要成本；
- 对不可行起点版本，右端项改为残差修正 $-r_p,\ -r_d$（$r_p=Ax-b,\ r_d=A^\top y+s-c$），迭代中残差自动收敛到 0；
- 注意 $\mu\to0$ 时 $x_i/s_i$ 趋于 $0$ 或 $\infty$，$AD^2A^\top$ **病态**——实用代码采用增广（不定型）系统、静态正则化、迭代精化等数值手段。
### 2.3 步长选择：Fraction-to-Boundary
牛顿方向可能把 $(x,s)$ 推出非负卦限，故取
$$
\alpha_{\max}=\min\Big\{\min_{\Delta x_i<0}\tfrac{-x_i}{\Delta x_i},\ \min_{\Delta s_i<0}\tfrac{-s_i}{\Delta s_i}\Big\},
\qquad
\alpha=\min(1,\ \gamma\,\alpha_{\max}),\ \gamma\approx 0.99
$$
保持 $x,s>0$ 严格内点。原始与对偶可用不同步长 $\alpha_p,\alpha_d$。
### 2.4 Mehrotra 预测-校正（实用版本的核心）
实践中的标配是 Mehrotra (1992) 算法，它自适应地选择 $\sigma$ 并补偿牛顿法的非线性误差：
1. **预测步**：取 $\sigma=0$（纯下降）解一次牛顿系统，得仿射方向 $\Delta^{aff}$，算出它能走多远，估计可达的 $\mu_{aff}$；
2. **自适应中心参数**：$\sigma = (\mu_{aff}/\mu)^3$（能降得多就激进，降不动就回中心）；
3. **校正步**：再解一次牛顿系统，第三块右端加入非线性补偿项 $\Delta X_{aff}\Delta S_{aff}\,e$；
4. 两次求解**共享同一个 Cholesky 因子**（一次分解、两次回代），效率极高。
### 2.5 复杂度
- 理论：短步路径跟踪法迭代次数为 $O(\sqrt n\,\log(1/\varepsilon))$（对数障碍自协调参数为 $n$），总复杂度多项式级别——这是相对单纯形法（最坏情形指数，Klee–Minty 1972）的理论优势；
- 实践：**迭代次数几乎与问题规模无关**，典型 10～60 次；总耗时由稀疏 Cholesky 决定。

## 三、完整算法步骤（Mehrotra 原始-对偶内点法）
```
输入: A, b, c; 初始点 x⁰>0, y⁰, s⁰>0; 容差 ε (如 1e-8)
─────────────────────────────────────────────────
repeat
  1. 计算残差与对偶间隙度量:
       r_p = Ax − b,   r_d = Aᵀy + s − c,   μ = xᵀs / n
  2. 收敛检查 (相对量):
       ‖r_p‖/(1+‖b‖) ≤ ε,  ‖r_d‖/(1+‖c‖) ≤ ε,  μ/(1+|cᵀx|) ≤ ε
     → 满足则停止, 输出
  3. 预测步 (σ=0): 解
       A Δxᵃ = −r_p
       AᵀΔyᵃ + Δsᵃ = −r_d
       S Δxᵃ + X Δsᵃ = −XSe
     (实现: 稀疏 Cholesky 分解 AD²Aᵀ, 求解正规方程 + 回代)
  4. αᵃ = fraction-to-boundary(Δxᵃ, Δsᵃ)
     μᵃ = (x+αᵃΔxᵃ)ᵀ(s+αᵃΔsᵃ)/n
     σ = (μᵃ/μ)³
  5. 校正步: 解
       A Δx = −r_p
       AᵀΔy + Δs = −r_d
       S Δx + X Δs = −XSe + σμe + ΔXᵃΔsᵃ
     (复用步骤3的 Cholesky 因子)
  6. α_p, α_d = min(1, 0.99·α_max)   (原始/对偶可分别取步长)
  7. 更新: x ← x + α_pΔx;  y ← y + α_dΔy;  s ← s + α_dΔs
until 收敛
─────────────────────────────────────────────────
输出: 近似最优的 (x, y, s) —— 注意: 一般【不是】基可行解!
```

## 四、Crossover：从内点解到最优基解
### 4.1 为什么需要 crossover
IPM 收敛到的点是**最优面的解析中心**，带来三个问题：
1. **解不稀疏**：大量变量取“小而正”的值（如 $10^{-9}$ 级别），既非精确零也非基变量，解向量通常近乎稠密；
2. **不是基解**：没有基的 ($B$) 结构。而混合整数规划（MIP）的分支定界**依赖基解**——分支变量选择、割平面加入后的热启动都基于基；后续 LP 重解也无法从内点解热启动；
3. **精度与认证**：IPM 精度受 $\mu\to0$ 时病态的制约（约 8–10 位有效数字），且没有“最优基”这样的组合证书。
**Crossover 就是桥梁**：从 IPM 的近似最优内点出发，用类似单纯形的主元操作，把它转化为一个**原始、对偶均可行的基（即最优顶点解）**，使输出与单纯形法完全同构。该思想源于 1990 年代（OB1 / Lustig–Marsten–Shanno；Megiddo 1991 证明了从近似内点求最优基的多项式方法），现在是所有主流 barrier 求解器的默认组件。
### 4.2 关键概念
设 LP 具有界形式 $\min c^\top x,\ \ell\le x\le u,\ Ax=b$，定义变量的三种状态：
| 状态 | 含义 |
|---|---|
| **基本（B）** | 在基中，$|B|=m$，$A_B$ 非奇异，取值由 $A_B x_B = b - A_N x_N$ 决定 |
| **非基本** | 固定在下界 $\ell_j$ 或上界 $u_j$ |
| **超基本** | 不在基中，却严格介于界之间 —— **这正是内点解的典型状态** |
Crossover 的目标：**消灭所有超基本变量**。理论基础是 LP 的**严格互补性**（Goldman–Tucker）：最优时每个 $i$ 恰有 $x_i>0$ 或 $s_i>0$ 之一成立，且最优划分 $P=\{i:x_i>0\},\ Z=\{i:s_i>0\}$ 唯一。IPM 的近似解恰好给出这个划分的可靠估计（$x_i\gg s_i$ 还是 $s_i\gg x_i$），crossover 据此选基，几乎“直奔”最优基。
### 4.3 Crossover 算法步骤
**阶段 0：解状态判定（snap / 划分）**
- 依据 IPM 输出的 $(x,y,s)$：$x_j\approx \ell_j$ → 非基下界；$x_j\approx u_j$ → 非基上界；其余标记为超基本候选；
- 利用 $x_j s_j$ 的大小比对做严格互补划分，判定哪些变量适合入基（$x_j$ 大）哪些应固定在界上（$s_j$ 大）。
**阶段 1：构造初始基**
- 从松弛变量的单位基出发，贪心地引入线性无关且稀疏的列（优先 $x_j$ 大者），用 **LU 分解 + Markowitz 准则**控制填充，得到初始基 $B$。
**阶段 2：主元循环（以原始 crossover 为例）**
```
while 存在超基本变量 j:
   1. 选一个超基本变量 j 入基 (如 |x_j| 最大者)
   2. 计算 BTRAN/FTRAN 得列 α = B⁻¹A_j
   3. 比率测试: x_j 变化时, 哪个基本变量最先碰界?
      - 若 x_j 自己先到对侧界 → bound flip (变量翻到另一界, 仍非基)
      - 否则该阻塞的基本变量出基
   4. 执行主元交换, 更新 LU 因子, 重解 A_B x_B = b − A_N x_N
   (循环中始终维持原始可行性)
```
每步至少消除一个超基本变量（或将其翻到界上），故主元次数与超基本变量个数同阶——实践中远少于从零开始的完整单纯形求解。
**阶段 3：对偶侧清理**
- 原始 crossover 结束后得到原始可行的基，但可能对偶不可行（约简价格符号不对）→ 跑**少量对偶单纯形迭代**清理至精确最优；
- 也有实现先做**对偶 crossover**（消除对偶超基本，得到对偶可行基），再用原始单纯形收尾。HiGHS 等会根据原始/对偶超基本数量选择先跑哪一侧。
**最终输出：一个原始、对偶都可行的基 = 最优基可行解**——至多 $m$ 个非零、带完整基结构，可任意热启动后续求解。
### 4.4 成本与实践特性
- crossover 耗时通常与 IPM 主循环同量级或更低（HiGHS 的实测经验）；
- 若 IPM 的最优划分判定准确，crossover 路径近乎“直线”；
- 若用户只需要近似最优解（如嵌入在更大的算法中），可关闭 crossover（如 Gurobi `Crossover=0`）省时间。

## 五、与单纯形法的系统比较
| 维度 | 单纯形法 | 内点法 + Crossover |
|---|---|---|
| **几何路径** | 沿多面体**边界**的顶点—棱移动 | 沿**中心路径**穿越可行域内部，最后 crossover 跳到顶点 |
| **方法论** | 组合/离散搜索（局部改善） | 连续最优化（障碍函数 + 牛顿法）+ 组合收尾 |
| **最坏复杂度** | 指数（Klee–Minty 立方体） | 多项式：$O(\sqrt n\log(1/\varepsilon))$ 次迭代 |
| **实际迭代数** | 随规模增长（经验 ~ $O(m)$ 量级），**每次极廉价**（稀疏 LU 更新） | 几乎恒定（10–60 次），**每次昂贵**（一次 Cholesky 分解） |
| **解的结构** | 基可行解（顶点），≤ m 个非零 | 解析中心（非基解）→ **crossover 补齐**为基解 |
| **退化** | 易停滞（stalling），防循环规则可避免循环 | 对退化不敏感，但 $\mu\to0$ 时正规方程病态 |
| **精度** | 可接近机器精度 | 约 8–10 位；crossover+单纯形收尾可再提高 |
| **热启动** | **极好**：基可直接复用；加割/改界后对偶单纯形是 MIP 节点的标配 | 本身难以热启动（须在中心路径附近，理论支撑弱，是研究热点）；crossover 产出的基正是其实际的热启动载体 |
| **不可行/无界检测** | Phase 1 / 对偶单纯形 | 自对偶嵌入、不可行性证书 |
| **并行性** | 主元操作本质串行 | 线性代数高度可并行（多线程/GPU） |
| **典型场景** | LP 序列、MIP 节点、中等规模 | 大规模稀疏、一次性求解 |
几个关键差别值得展开：
**（1）“复杂度悖论”**：单纯形最坏指数但实际极快（Klee–Minty 是人工构造）；内点法多项式但每次迭代常数大。两者并非替代关系，而是互补——商业求解器普遍采用**并发策略**：同时开多线程跑原始单纯形、对偶单纯形和 barrier，谁先完成用谁的结果。
**（2）输出解的哲学不同**：单纯形天然输出“极端点”解（稀疏、可解释、可热启动）；纯内点法输出“折中”解（最优面中心、对某些应用如机器学习中的 LP 反而更均衡）。crossover 的存在说明工程实践中“基解”仍是硬需求——尤其在 MIP 中，根节点 LP 用 barrier+crossover 得到基，后续所有节点用对偶单纯形热启动，是标准打法。
**（3）每步成本结构完全不同**：单纯形一步 = 一次 BTRAN/FTRAN + 定价 + 比率测试，代价 $O(\text{nnz})$ 且高度稀疏；内点法一步 = 一次完整的 $m\times m$ 对称正定系统分解。这决定了内点法对**稠密列、填充爆炸**的稀疏结构敏感，而单纯形对**超大规模迭代数**敏感。
**（4）退化与鲁棒性**：高度退化的 LP（如网络流、调度）会让单纯形大量停滞；内点法的迭代数几乎不受退化影响，这是它在某些大规模退化问题上的显著优势。

## 六、总结
```
内点法 + Crossover 完整流水线:
  原始-对偶内点法 (Mehrotra 预测-校正)
     │  沿中心路径 √n 级多项式迭代收敛
     │  每步: 稀疏 Cholesky 解 AD²AᵀΔy = g
     ▼
  近似最优内点解 (最优面的解析中心, 非基解)
     │
     │  Crossover
     │  划分变量 → 构初始基 → 主元消超基本 → 单纯形收尾
     ▼
  最优基可行解 (顶点, 与单纯形输出同构, 可热启动)
```
- **内点法**回答“如何在多项式时间内逼近 LP 最优解”（连续化 + 牛顿法 + 中心路径）；
- **Crossover** 回答“如何把内点解转化成工程上需要的基解”（利用严格互补划分 + 单纯形式主元）；
- **单纯形法**则是另一条完整路线：边界上的顶点搜索，最坏慢、实际快、热启动无敌。
选型经验法则：**大规模稀疏 LP 一次性求解用 barrier（+crossover）；LP 反复重解或 MIP 节点用（对偶）单纯形**；不确定时交给求解器的自动选择或并发模式。
如果想深入，推荐阅读：Wright《Primal-Dual Interior-Point Methods》、Mehrotra (1992) 原始论文、Megiddo (1991) 关于最优基的论文，以及 HiGHS 团队关于其 IPM 与 crossover 实现的论文（开源代码可直接研读）。

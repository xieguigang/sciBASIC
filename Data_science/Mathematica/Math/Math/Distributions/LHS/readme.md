# Latin Hypercube Sampling（拉丁超立方采样，LHS）详解
这是论文实验流程中非常关键的一环（论文引用的就是 LHS 的奠基文献之一：Iman, Davenport & Zeigler, 1980）。下面从动机、原理、算法步骤、与普通蒙特卡洛的对比、工程实现几个层面讲解。
---
## 一、为什么需要 LHS——问题动机
在拓扑搜索系统中，每个拓扑有 $n_p = 2n_l + 2$ 个参数（$n_l$ 为链接数），要对参数空间采样 10,000 组来评估拓扑的鲁棒性 Q 值。这本质上是一个**高维空间填充问题**：我们希望用有限的采样点尽可能均匀、全面地覆盖参数空间，不漏掉任何重要区域。
普通蒙特卡洛（Monte Carlo, MC）的做法是每个参数独立均匀随机取值。它有一个明显缺陷：
- 由于纯随机的“聚类效应”，样本点可能**成堆地落在某些区域**，而另一些区域**一个点都没有**；
- 两个本不该有关系的参数还可能因随机性出现**虚假相关**；
- 这意味着计算资源被浪费在重复区域，而稀疏区域（可能恰恰藏着功能行为，比如论文中狭窄的“饱和区”）被漏采。
**LHS 的核心思想**：对每一个维度做**分层（stratification）**——把每个参数的取值区间等分成 N 个互不重叠的子区间，保证**每个子区间里恰好有一个样本**，然后在各维度间随机配对组合。
---
## 二、LHS 的算法步骤
要生成 $N$ 个样本点、维度为 $d$ 的 LHS 设计：
**第 1 步：每个维度分层**
把 $[0,1)$ 切成 $N$ 个等概率小区间：
$$\left[0, \tfrac{1}{N}\right), \left[\tfrac{1}{N}, \tfrac{2}{N}\right), \ldots, \left[\tfrac{N-1}{N}, 1\right)$$
**第 2 步：每个维度内各取一点**
在每个子区间内取一个随机点（Random LHS）或取区间中点（Median LHS / 中心化 LHS）：
$$x_j^{(i)} = \frac{\pi_j(i) + u}{N}, \quad u \sim U[0,1)$$
其中 $\pi_j$ 是第 $j$ 个维度上 $\{0,1,\ldots,N-1\}$ 的一个随机置换，$u$ 是区间内的随机抖动。
**第 3 步：跨维度随机配对**
对每个维度独立地做一个随机置换 $\pi_j$，把各维度的 N 个取值“洗牌”后逐行组合，形成 N 个 d 维样本点。
**关键保证**：
- **一维边缘分布完美分层**：沿任何一个参数轴投影，N 个点恰好一格一点，绝不重叠、绝不遗漏；
- **随机置换保证维度间无系统相关**（除非刻意引入相关性）；
- 几何上这类似于拉丁方（Latin square）——每行每列恰好一个元素——推广到高维“超立方体”，故得名拉丁**超立方**。

## 三、LHS vs 普通蒙特卡洛：理论优势
**1. 方差缩减 / 收敛速度**
这是 LHS 最重要的理论性质。对于估计积分/均值：
- MC 的估计误差随样本量按 $O(N^{-1/2})$ 下降；
- LHS 对几乎所有常用分布和统计量按 $O(N^{-1})$ 下降——**平方级加速**。
也就是说，LHS 用 N 个样本达到的精度，MC 需要 $N^2$ 个样本才能达到。有一个严格结论：**N 点 LHS 的积分方差恒小于 N−1 点普通 MC**（SciPy 文档 Notes 部分引述了 Stein 1987、Owen 1997 的结果）。
**2. 一维投影均匀性**
LHS 保证所有一维投影都完美分层。这对拓扑搜索特别有价值：**当功能行为只对某单一参数敏感（如必须满足 K < 0.01 的饱和条件）时，LHS 保证该参数的整个动态范围都被覆盖到，不会因为运气不好而漏掉关键区间**。
**3. 高维表现与限制**
需要注意诚实的另一面：
- LHS 的优势在**低维（约 ≤3 个主导参数）且各参数贡献相当**时最显著；
- 高维下，维度间随机配对带来的随机性成为主导，LHS 与 MC 的实际差距缩小；
- 但在实践中，即使有几十个参数，往往只有少数几个主导不确定性来源，所以 LHS 通常仍有可观收益。

## 四、在论文场景中的具体用法
论文中的采样有三个值得注意的细节：
**1. 对数空间均匀采样**
```python
lb = np.tile([-1, -3], ...)[:n_params]   # log10(k)∈[-1,1], log10(K)∈[-3,2]
ub = np.tile([ 1,  2], ...)[:n_params]
log_params = lb + lhs_unit * (ub - lb)
params = 10.0 ** log_params
```
在 $[0.001, 100]$ 这样的 5 个数量级范围内做线性采样，99% 的点会堆在高端；而在 log 空间采样，**每个数量级被分配同等采样密度**——这与 LHS 的分层思想天然契合，确保饱和区（小 K）、线性区（大 K）、中间区都被充分覆盖。这是拓扑搜索能否发现 NFBLB（需要饱和）和 IFFLP（需要饱和+线性组合）的关键。
**2. 采样量与 Q 值的统计关系**
每个拓扑采 10,000 组，Q 值 = 落入功能区（S>1, P>10）的参数组数量。由于功能区域在参数空间中可能是很小的“孤岛”，采样越均匀，估计的 Q 值越无偏。LHS 的边缘分层性质保证了像“K 全都 < 0.01”这类组合条件至少有一批样本落在其中。
**3. 固定随机种子**
为保证可复现性（以及断点续跑），采样器必须绑定固定 seed：
```python
sampler = qmc.LatinHypercube(d=n_params, seed=42)
```

## 五、工程实现
SciPy 的 `scipy.stats.qmc` 模块提供了生产级的 LHS 实现：
```python
from scipy.stats import qmc
import numpy as np
# 生成 10,000 个 12 维样本
sampler = qmc.LatinHypercube(d=12, seed=42)
unit = sampler.random(n=10_000)          # shape (10000, 12), 取值 [0,1)
# 缩放到实际参数范围（对数空间）
l_bounds = [-1, -3] * 6
u_bounds = [ 1,  2] * 6
log_params = qmc.scale(unit, l_bounds, u_bounds)
params = 10.0 ** log_params
# 评估样本质量（centered discrepancy，越小越均匀）
print(qmc.discrepancy(unit))
```
SciPy 还提供两个增强选项：
- **`optimization="random-cd"`**：通过随机坐标置换最小化 centered discrepancy，改善 2D/3D 投影的空间填充度——可以弥补纯 LHS 只保证一维投影的短板；
- **`strength=2`**：基于正交数组（orthogonal array）的 LHS，使**二维投影也近似均匀**（要求 $N = p^2$、$p$ 为素数）——若怀疑功能行为取决于两个参数的特定组合（如 $K_{CB}$ 与 $K'_{FB}$ 同时小），这个选项很有用。
其他可选库：`pyDOE2`、`SMT`（提供 center/maximin/correlation/ESE 等五种优化准则）、`salib`（SALib，敏感性分析生态）。
**动手实现核心算法（约 10 行）**：
```python
import numpy as np
def lhs(n_samples, n_dim, rng):
    # 每维：分层索引的随机置换 + 区间内均匀抖动
    u = (rng.permuted(np.tile(np.arange(n_samples), (n_dim, 1)), axis=1)
         + rng.random((n_dim, n_samples))) / n_samples
    return u.T   # (n_samples, n_dim)，每列均为 [0,1) 的完美分层
```

## 六、注意事项与陷阱
1. **LHS 不消除维度间相关性问题**：随机配对在有限样本下仍会产生抽样相关。如需控制参数间相关性结构，可用 Iman-Conover 方法做重排。
2. **不要重复使用同一批 LHS 样本去“追加”采样**：追加的新样本会破坏整体的分层性，若要扩大样本量应重新生成完整设计（或使用专门的可扩展 LHS 方案）。
3. **discrepancy 是质量指标**：用 `qmc.discrepancy` 检查样本均匀度，多个 seed 生成后择优，是廉价的改进手段。
4. **与 Sobol/Halton 序列的取舍**：对于固定的静态参数空间，scrambled Sobol 序列往往比 LHS 更均匀；LHS 的优势在于**样本数灵活可先定**、以及可以增量扩展（fast_forward），且在接近可加的函数上理论方差性质极好。
5. **结果报告**：由于采样有随机性，报告 Q 值时最好注明采样方案与 seed，或者用多个独立 LHS 设计重复实验给出 Q 值的置信区间。
---
## 七、一句话总结
LHS = **“每个维度各自完美分层 + 跨维度随机配对”**：它把普通蒙特卡洛的“听天由命式”覆盖升级为对每个参数轴的**保证性覆盖**，在对数空间中配合使用，能以平方级更少的样本达到同等精度——这正是论文能以每拓扑 10,000 组参数、总共约 $1.6\times10^8$ 次仿真，可靠地分辨出 395 个稳健适应拓扑的统计基础。

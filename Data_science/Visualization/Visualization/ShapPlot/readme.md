SHAP 可视化结果图主要包括以下几类：**摘要蜂群图、特征重要性柱状图、单样本瀑布图、力导向图、依赖图、决策图、热力图和小提琴图**，它们分别服务于全局特征解释、单样本归因和特征交互分析三大场景。
## 核心图表速览
| 图表名称 | 对应函数 | 解释层级 | 典型用途 |
|---------|---------|---------|---------|
| 蜂群图 | `shap.plots.beeswarm` / `shap.summary_plot` | 全局 | 观察所有样本上每个特征的影响方向与分布 |
| 特征重要性柱状图 | `shap.plots.bar` | 全局 | 快速获得特征平均贡献排名 |
| 瀑布图 | `shap.plots.waterfall` | 局部 | 逐步拆解单个样本从基准值到预测值的贡献 |
| 力导向图 | `shap.plots.force` / `shap.force_plot` | 局部/全局 | 紧凑展示单样本正负推力，或堆叠观察整体趋势 |
| 依赖图（散点图） | `shap.plots.scatter` / `shap.dependence_plot` | 交互 | 揭示特征值与 SHAP 值的非线性关系及特征交互 |
| 决策图 | `shap.plots.decision` | 局部/多样本 | 展示累积 SHAP 值如何引导模型做出决策路径 |
| 热力图 | `shap.plots.heatmap` | 全局 | 以颜色矩阵同时呈现样本与特征的 SHAP 分布 |
## 各类图表详解
### 1. 蜂群图
蜂群图以信息密集的方式展示数据集中顶部特征对模型输出的整体影响，是 SHAP 全局解释最常用的可视化形式。图中每一行代表一个特征，纵轴按平均 |SHAP| 值大小排序；每个点代表一个样本，横轴为该样本在此特征上的 SHAP 值，颜色红蓝分别表示特征值的高低。
解读要点：**颜色越红的点若集中在右侧，说明该特征取值高时显著推高预测输出**；反之蓝色点在左侧则表示低取值拉低预测。点的横向散布越宽，说明该特征的影响在不同样本间差异越大。
```python
import shap
explainer = shap.TreeExplainer(model)
shap_values = explainer(X)
shap.plots.beeswarm(shap_values, max_display=15)
```
### 2. 特征重要性柱状图
柱状图对每个特征取所有样本 SHAP 值的绝对值平均，给出最直观的特征排名。相比蜂群图，它丢失了方向信息（正/负贡献），只反映重要性大小，适合作为报告或论文中的简化展示。
```python
shap.plots.bar(shap_values)  # 或 shap.summary_plot(shap_values, X, plot_type="bar")
```
### 3. 瀑布图
瀑布图是对单个预测最完整的展示，它以瀑布结构强调正负贡献的可加性——从基准值出发，各特征的正负贡献逐级叠加，最终到达模型的预测值。红色条代表正向推力，蓝色条代表负向推力，条宽即为 SHAP 值大小。
```python
shap.plots.waterfall(shap_values[0])  # 解释第一个样本
```
### 4. 力导向图
力导向图与瀑布图在信息上等价，但以更紧凑的水平布局呈现：将预测推向更高的特征显示为红色，推向更低的显示为蓝色，从基准值向两侧伸展。当将多个样本的力图堆叠并旋转后，还能观察模型在全体样本上的输出趋势变化。
```python
shap.plots.force(explainer.expected_value, shap_values.values[0], X.iloc[0])
```
### 5. 依赖图
依赖图类似于部分依赖图（PDP），但额外包含了特征交互信息：X 轴为特征实际取值，Y 轴为对应 SHAP 值，通过散点分布可直接看出特征与预测间的线性、非线性关系。当存在强交互时，图中颜色维度（交互特征）会呈现明显的分层。
```python
shap.plots.scatter(shap_values[:, "Age"], color=shap_values)
```
### 6. 决策图
决策图展示模型如何通过累积 SHAP 值逐步做出预测，每条折线解释一个样本的决策路径，便于比较多条样本或识别异常路径。绘制单条样本时还会在图中打印特征的具体取值，适合向非技术干系人讲解模型决策过程。
```python
shap.decision_plot(explainer.expected_value, shap_values.values, X)
```
### 7. 热力图
热力图以样本 × 特征的矩阵形式呈现 SHAP 值，并附上模型输出曲线，能同时观察特征贡献模式随样本排序的变化，常用于发现样本聚类结构。
```python
shap.plots.heatmap(shap_values)
```
### 8. 小提琴图
小提琴图可视为蜂群图的平滑替代（`shap.summary_plot(..., plot_type="violin")`），用核密度估计展示各特征 SHAP 值的分布形态，在样本量极大时比蜂群图更易读。
## 选择建议
实际使用时可遵循以下组合思路：**论文与汇报中最常见"摘要蜂群图 + 特征重要性柱状图 + 依赖图"组合，兼顾整体特征排名、方向解释和交互挖掘**；若需向业务方解释单个具体案例（如一笔被拒的贷款申请），瀑布图与力导向图是首选；若需诊断多组样本的决策路径差异或识别离群样本，则使用决策图与热力图。

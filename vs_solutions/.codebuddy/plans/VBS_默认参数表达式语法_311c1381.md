## 产品概述

为 VBS 脚本引擎（`VBS/VBS.vbproj`）新增「默认参数表达式」脚本语法：顶层 `Function`/`Sub` 的 `Optional` 参数可以书写**任意可产生值的表达式**作为默认值（不再局限于常数与常数表达式），引擎在脚本编译前自动把这种写法改写成等价且可被 Roslyn 编译的代码，脚本作者无需任何额外声明。无界面变更，全部是脚本语法与生成代码的行为变化。

## 核心功能

1. **非常数默认值表达式**：默认值可引用同一函数中更靠前的参数、模块级变量、`New` 构造与其它函数调用，例如 `Optional c As data = If(b, New testdata(a), New testdata("default"))`。
2. **声明自动改写**：含非常数默认值的参数被改写为 `Optional c As data = Nothing`（保留 `Optional`、类型子句与其余常量默认参数），从而满足编译要求。
3. **`Function` 调用点改写（桥接函数）**：为「省略了至少一个动态默认参数的调用点」按需生成顶层桥接函数，调用点只替换被调用名、实参表原样保留，因此 `While test(a,b)`、`If test(...) Then`、`print(test(...))` 等任意表达式位置均可支持，且不改变求值顺序与具名实参语义。
4. **`Sub` 调用点改写（就地多行临时变量）**：Sub 调用只可能是语句，故直接把 `Call test(a:="xxxxx", b:= check())` 展开为多行——先按书写顺序物化全部实参，再按声明顺序计算被省略参数的默认值，最后按声明顺序完整调用；不引入桥接函数，避免 Sub 热点调用的额外开销。
5. **语句容器展开**：当 Sub 调用位于无法容纳多行语句的单行结构中时，先把该结构展开为块再插入临时变量行——单行 Sub lambda（`Dim f = Sub() Call test(a, check())`）展开为多行 lambda；单行 `If <条件> Then <调用>` 展开为 `If ... End If`。
6. **未覆盖即编译期报错**：若某函数存在「找到了但无法改写」的调用点，则把其动态默认参数退化为**必填**，让这些调用点在编译期报「未提供参数」，绝不静默取到 `Nothing`；已被改写的调用点不受影响。
7. **作用域等价**：默认值表达式可正确引用模块级变量；桥接函数中被省略参数用同名局部量承载，因此默认值表达式原样复用、无需名字替换。
8. **最小侵入与命名安全**：常量默认参数保持原样；提供了全部参数的调用点保持原样；不含非常数默认参数的函数完全不受影响；桥接函数名与临时变量名均带前缀与全局序号并做全文符号冲突检查。

## 技术栈

- 语言与工程：复用现有 VB.NET 工程 `VBS/VBS.vbproj`（`net10.0`、`LangVersion 16`、`RootNamespace VBScriptHost`、`AssemblyName vbs`），**不新增任何第三方依赖**。`Microsoft.CodeAnalysis.VisualBasic 5.9.0` 与 `Microsoft.VisualBasic.Core` 的 ProjectReference 已存在，可按需复用。
- 工程为 SDK 风格、默认通配包含 `src/**`（`<ItemGroup>` 中仅 `Compile Remove="test\**"`，已核实第 41-45 行），因此**新增源文件无需修改工程文件**。
- 实现风格沿用既有文本预处理阶段（`LetStatement` / `TupleDestructuring` / `PropertyProjection`）：逐行处理、等长掩码、括号配平扫描、不确定即放弃。本阶段**不需要 Roslyn 语义模型**，只用文本级改写。
- 可复用既有成员：`PropertyProjection.MaskLiterals`（`Friend Shared`，等长空格掩码，偏移可直接复用原文）、`ScriptStructure.SplitTopLevel` / `IsFunctionBlockStart` / `IsTypeBlockStart` / `IsBlockEnd` / `IsNestedBlockStart` / `IsControlBlockStart` / `IsLambdaBlockStart` / `DeclaredNamesOf`（均 `Friend`）。`VectorExpressionRewriter.ExtractParameterList` / `MatchingClose` 为 `Private`，新模块自带同形状私有副本，不扩大改动面。

## 实现方案

**核心策略**：在 `ScriptRefactor.PreprocessText` 文本预处理链中插入新阶段 `DefaultParameterExpression.Expand(source, report)`，一次扫描分四趟：收集顶层声明 → 改写调用点（函数走桥接、Sub 走就地展开）→ 改写声明 → 末尾追加桥接函数。

**为什么 Function 用桥接函数、Sub 用临时变量**：VB 中 Sub 调用只能作为语句出现（不存在 `Return sub(...)` / `While sub(...)`），因此「在该语句之前插入多行」永远安全，无需桥接函数，也就不给 Sub 的热点调用增加一次函数调用；而 Function 可以出现在任意表达式位置，桥接函数把「默认值求值」搬进真正存在的函数作用域，使调用点退化为词元级名字替换。

**Function 路径（路径 A）**

- 为「省略了至少一个动态默认参数的调用点」按「提供的参数名列表（声明顺序）」为 key 生成顶层桥接函数：
`Function <名>_defaults(<该调用点提供的参数，按声明顺序，沿用原修饰符与 As 子句>) As <原返回类型>`，函数体为每个**被省略的参数**按声明顺序生成 `Dim <参数名> = <默认值原文>`，最后 `Return <原名>(<全部参数按声明顺序>)`；`Sub` 形态则为 `Sub <名>_defaults(...)` + `Call <原名>(...)`。
- 桥接函数形参名与被省略参数生成的局部量名**都与原参数同名**，因此默认值表达式**原样复制、零名字替换**；调用点只把被调用名替换为桥接函数名、**实参表原样保留**，故任意表达式位置都可支持，且不改变求值顺序与具名实参语义。
- 桥接函数名 `<原函数名>_defaults`，冲突追加数字后缀（生成前对整份脚本文本做词边界检查）。
- 桥接函数追加在脚本文本末尾（带生成注释头）；它是顶层 `Function` 块，自动进入 `ScriptStructure.Scan`：运行期被重写为匿名函数并由 `ResolveFunctionSlots` 依「引用了原函数 + 默认值表达式引用的模块级变量」求解落位；工程期被还原为模块级 `Private Function`，默认值表达式引用的顶层变量由既有 `ResolveFields` 提升为字段。两条发射路径均无需额外改动。

**Sub 路径（路径 B）**

- 展开形态（统一按「物化全部被提供的实参」，严格保序）：

1. 先按**书写顺序**为**全部被提供的实参**生成 `Dim <tmp> = <实参原文>`（简单标识符与字面量也一并物化，使求值次序严格保持「实参（书写顺序）→ 默认值 → 调用」，与 VB 左到右求值一致；物化简单实参只是多一条等价局部量，语义无差异）；
2. 再按**声明顺序**为**全部被省略的参数**生成 `Dim <tmp> = <默认值表达式（参数名替换为对应 tmp 名）>`（常量默认值与动态默认值一视同仁，因为其后可能还有需要位置传入的参数）；
3. 最后按**声明顺序**完整传入调用（保留原有的 `Call` 与否），实参表改为位置形式。

- 支持的语法上下文：

1. 该行只有一条语句（允许前导空白、可选 `Call`、行尾注释）→ 直接在该行之前插入临时变量行，缩进沿用原行前导空白，行尾注释跟随最后一条调用行；
2. 多行 lambda 体内的独立语句行 → 同 (1) 天然支持；
3. **单行 Sub lambda 的语句体**（`Dim f = Sub(参数) <调用>` / `xxx = Sub(...) <调用>` 位于行尾）→ 展开为多行 lambda 块，`End Sub` 单独成行；仅当该 lambda 位于赋值/`Dim` 右侧行尾时展开（与既有 `ScriptStructure.IsLambdaBlockStart` 支持的多行 lambda 形态一致），出现在调用实参等其它位置 → 计入「无法覆盖」；
4. **单行 `If <条件> Then <调用>` 的 Then 分支**（整行恰好是该形式，无 `Else`/`ElseIf`）→ 展开为 `If <条件> Then` / 临时变量行 / 调用 / `End If`；
5. 其余一律计入「无法覆盖」：`Else`/`ElseIf` 分支内嵌单行调用、冒号分隔的多语句行、实参表跨物理行（`_` 续行）、无括号 Sub 调用 `test a, b`、括号不配平或实参解析失败。

- 临时变量命名与名字替换：临时变量名形如 `__vbs_<subName>_<paramName>_<全局序号>`（用户明确允许"名称可以更加复杂些，以避免可能的符号名称冲突"）；默认值表达式里出现的**参数名必须做词元级替换**为该 tmp 名，替换建立在 `MaskLiterals` 的等长掩码之上以跳过字符串/注释，并排除成员访问前置 `.`。全局序号保证同一作用域内多处展开的临时变量不重名（同作用域重复 `Dim` 会报重定义），生成前再用整份脚本文本词边界检查兜底。

**「无法覆盖」处理（用户选定）**：若某函数存在「找到了但无法改写」的调用点，则把该函数的**动态**默认参数退化为**必填**（删掉 `Optional` 与默认值），让这些调用点在编译期报「未提供参数」，绝不静默取到 `Nothing`；已被改写的调用点不受影响。判定方式：记录被成功改写的名字出现偏移，文本中其余「非声明行、非成员访问（前置 `.`）、非 `AddressOf`」的函数名出现一律视为疑似未覆盖调用点（宁判为未覆盖，代价仅是该函数失去 `= Nothing` 兜底）。

**保守放弃条件**（不改写该函数，声明保留原默认值 → Roslyn 报「常量表达式必需」，与今天一致，不存在行为回归）：含 `ParamArray`；含方法泛型类型参数表 `(Of T)`；参数类型子句出现除 `()` 数组标记以外的括号（如 `x As List(Of Integer)`，既有 `ToLambdaSignature` 的 `\([^)]*\)` 同样不支持）；参数表跨物理行（括号不配平）；某默认值表达式引用自身参数名或更靠后的参数名；类型定义块内部存在同名 `Function`/`Sub` 成员（名字遮蔽）；需做名字替换时默认值表达式含 lambda 且其形参名与被替换的参数名冲突。另外：**`Sub` 若声明了 `ByRef` 参数，退回路径 A 的桥接函数**（桥接按 `ByRef` 转发可保引用语义；路径 B 把实参物化成局部量会丢失回写）；`Function` 的桥接路径天然保留 `ByRef`。

**关键决策与取舍**

1. 常量分类取保守方向：仅字面量、`True`/`False`/`Nothing` 及其一元正负、算术/拼接/括号判为常量；其余（含十六进制、日期字面量、枚举常量）一律判为动态——误判为动态只是多做一次等价改写，漏判才危险。
2. 兼容优先：`PreprocessText` 只新增**可选**参数，既有 4 处调用方（`ScriptRefactor.Refactor`、`VBScript.ParseScript`、`ProjectCodeBuilder.BuildIncludedSources`、`IncludeResolver`）零改动；不修改 `ScriptParseResult`。
3. 性能：整体为单趟文本扫描，每行一次掩码 O(行长)，与既有阶段同级；桥接函数数量上界为「各函数的不同调用点子集数」，实际远小于调用点数；Sub 路径为纯内联展开，零额外调用开销；无额外 IO、无编译开销、无内存放大。

## 实现说明（执行细节）

- 插入位置：`VBS/src/VBScript/Syntax/ScriptRefactor.vb` 的 `PreprocessText`，在 `TupleDestructuring.Expand(code)` 之后、`Vectorization.Expand(...)` 之前（第 76-78 行之间）。这样桥接函数体与生成的临时变量行也能被 `@` 投影与 SIMD 向量化处理，且运行期与工程期两条路径自动一致。
- 偏移与回写：一律基于 `MaskLiterals` 的等长掩码定位（掩码偏移可直接用于原文）；同一物理行多处替换必须**从右向左**回写；不做全行重排。
- 只改必要部分：声明改写只替换动态参数的 `= 表达式` 区间；Function 调用点只替换被调用名那段字符；Sub 展开只重建该条语句与插入其前的临时变量行。
- 不动既有行为：不修改任何既有阶段逻辑与公开签名（仅新增可选参数）；常量默认参数、全参调用、无默认参数函数原样输出；`#include` 引入的脚本不允许顶层函数与顶层语句，本阶段对其为空操作。
- 生成代码可读性：末尾追加的桥接函数带生成注释头（原函数签名与改写说明），便于 `--verbose` 与 `make-project` 之后人工核对。
- 报告与诊断：新增 `DefaultParameterReport`，沿用既有 `--verbose` 输出块打印改写调用点数、桥接函数名、就地展开的 Sub 名、退化为必填的参数（形如 `test.c`）、放弃改写的函数名；不引入日志框架、不输出脚本内容以外的敏感信息。
- 错误处理：任何解析失败都返回明确的失败信号并按「放弃 / 退化必填」策略处理，绝不抛异常中断编译，也不生成猜测性代码。

## 架构设计

新阶段是既有线性预处理流水线中的一环，产物仍是「可直接被 Roslyn 编译的脚本文本」，不改动下游的扫描与发射阶段。

```mermaid
flowchart LR
    A[#include 剔除 / ?参数展开] --> B[let 展开]
    B --> C[元组分解展开]
    C --> D[默认参数表达式改写 NEW]
    D --> E[向量化 与 @ 投影展开]
    E --> F[ScriptStructure 扫描与代码发射]
```

模块职责划分：

- `DefaultParameterExpression`：阶段入口 `Expand`；顶层函数块声明收集（自带轻量块深度扫描）；Function 桥接路径与 Sub 就地展开路径的调用点编排（含单行 Sub lambda / 单行 `If ... Then` 的块展开）；声明改写；覆盖判定与报告汇总；末尾追加桥接函数。
- `DefaultParameterSignature`：签名与参数的文本解析模型（参数项拆分、默认值常量/动态分类、修饰符与类型子句提取）、桥接函数源码发射、参数名到临时变量名的词元级替换工具、命名冲突规避。

二者与既有阶段的边界：只做文本变换并输出脚本文本，不触碰 `ScriptStructure` / `ScriptRefactor.BuildCode` / `ProjectCodeBuilder`。

## 关键代码结构

生成的代码形态是本阶段唯一的输出契约（运行期与工程期两条发射路径共同消费）：

```
' 路径 A: Function => 末尾追加桥接函数, 调用点只改被调用名
' 原函数: Function test(a As String, b As Boolean, Optional c As data = If(b, New testdata(a), New testdata("default")))
' 声明改写为: Function test(a As String, b As Boolean, Optional c As data = Nothing)
Function test_defaults(a As String, b As Boolean) As data
    Dim c = If(b, New testdata(a), New testdata("default"))
    Return test(a, b, c)
End Function

' 路径 B: Sub => 调用点就地多行展开
' Call test(a:="xxxxx", b:= check())  =>
Dim __vbs_test_a_1 = "xxxxx"
Dim __vbs_test_b_2 = check()
Dim __vbs_test_c_3 = If(__vbs_test_b_2, New testdata(__vbs_test_a_1), New testdata("default"))
Call test(__vbs_test_a_1, __vbs_test_b_2, __vbs_test_c_3)

' 路径 B: 单行 Sub lambda 先展开为多行 lambda 块
' Dim lambda = Sub() Call test(a, check())  =>
Dim lambda = Sub()
                 Dim __vbs_test_b_2 = check()
                 Dim __vbs_test_c_3 = If(__vbs_test_b_2, New testdata(a), New testdata("default"))
                 Call test(a, __vbs_test_b_2, __vbs_test_c_3)
             End Sub
```

报告类型（仅供 `--verbose` 消费，不进入编译产物）：

```
Public Class DefaultParameterReport
    Public Property Rewritten As Integer                          ' 被改写的调用点数
    Public ReadOnly Property InlineSubs As New List(Of String)    ' 就地展开的 Sub 名
    Public ReadOnly Property Bridges As New List(Of String)       ' 生成的桥接函数名
    Public ReadOnly Property Required As New List(Of String)      ' 退化为必填的参数(形如 "test.c")
    Public ReadOnly Property Skipped As New List(Of String)       ' 因保守条件放弃改写的函数名
End Class
```
